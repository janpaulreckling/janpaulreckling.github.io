# janpaulreckling.github.io

Portfolio site: https://janpaulreckling.github.io

A single static page (HTML and CSS, no build step) introducing two connected back-office projects for the fictional outdoor retailer Northwind Outfitters:

- [order-to-cash-sync](https://github.com/janpaulreckling/order-to-cash-sync): from won deal to paid invoice, with a [live dashboard](https://janpaulreckling.github.io/order-to-cash-sync/dashboard/)
- cash-reconciliation-engine: from payment to closed books (coming December 2026)
